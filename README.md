# Beam for Safari

A Safari extension for macOS: right-click a video, choose **Beam to Apple TV**, and Safari's own AirPlay picker opens for that video. No servers, accounts or data collection.

Status: early build, working on most test pages. See `docs/STATUS.md` for exactly where things stand and how to run it, `PRODUCT.md` for the product, `DESIGN.md` for the design system, and `prd.md` for the task list.

Build and test commands are in `CLAUDE.md`. Built under a launch-readiness workflow: nothing here claims legal compliance or store readiness.
